# Homebrew Tap for Parallax Wallpaper

Official Homebrew Tap for [Parallax Wallpaper](https://github.com/alphastar-avi/ParallaxWall) by [@alphastar-avi](https://github.com/alphastar-avi).

---

## Installation

Install Parallax Wallpaper with a single command:

```bash
brew install alphastar-avi/tap/parallexwall
```

Homebrew will download the latest release `.dmg`, link `parallexWall.app` into `/Applications`, and automatically configure Gatekeeper attributes so the app launches on the first click.

---

## Updating / Upgrading

To update to the latest release whenever a new version is published:

```bash
brew update
brew upgrade parallexwall
```

---

## Uninstalling

To uninstall Parallax Wallpaper:

```bash
brew uninstall --cask parallexwall
```
